## 維護方式

首頁內容放在根目錄的 `index.html`。若使用 GitHub Pages，將發布來源設為 `main` 分支的根目錄 `/(root)`；之後提交 `index.html` 的更新，網站就會跟著更新。

這是公開 repository，因此這裡的檔案和 commit 歷史都能被查看。本 repo 只放入口頁與專案連結，不複製各專案 repository 的程式碼。Notion 文件的閱讀權限仍由 Notion 的分享設定管理。
